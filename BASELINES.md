# Baseline Implementations

Baseline scores in the main comparison table are taken from the original [HyenaRec paper](https://arxiv.org/abs/2603.25027). Public implementations of the compared models are listed below.

| Model | Implementation |
|---|---|
| GRU4Rec | https://github.com/hidasib/GRU4Rec_PyTorch_Official |
| NARM | https://github.com/lijingsdu/sessionRec_NARM |
| SASRec | https://github.com/kang205/SASRec |
| BERT4Rec | https://github.com/FeiSun/BERT4Rec |
| EulerFormer | https://github.com/RUCAIBox/EulerFormer |
| HSTU | https://github.com/meta-recsys/generative-recommenders |
| LRURec | https://github.com/yueqirex/LRURec |

The original Legendre-based HyenaRec and Ordered Spectral HyenaRec are implemented in this repository.
